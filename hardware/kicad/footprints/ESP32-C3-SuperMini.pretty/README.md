# ESP32-C3 Super Mini Footprint

Enthält den KiCad-Footprint `MODULE_ESP32-C3_SUPERMINI_TH.kicad_mod` für ein ESP32-C3 Super Mini Through-Hole-Modul.

## Herkunft

Quelle des übernommenen Footprints:

- Repository: `abhijithvijayan/wireless-steering-wheel-controls`
- Pfad: `circuit/custom/MODULE_ESP32-C3_SUPERMINI_TH.kicad_mod`

Das Quellprojekt verweist für diese ESP32-C3-SuperMini-KiCad-Dateien auf SnapMagic/SnapEDA und nennt **CC BY-SA 4.0 mit Design Exception 1.0**.

## Wichtig für unser Projekt

Der Footprint ist noch mit dem real gekauften **DUBEUYEW ESP32-C3 Super Mini** zu prüfen.

Bitte vor endgültiger Verwendung kontrollieren:

- Außenmaße der Platine
- Abstand der beiden Pinreihen
- Rastermaß der Pins
- Lage der USB-C-Buchse
- Pinbeschriftung / Pinreihenfolge
- Bohrungsdurchmesser

Empfohlen: 1:1 aus KiCad drucken und das reale Modul direkt auflegen.
